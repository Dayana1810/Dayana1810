# DAYANA — Data Analyst Portfolio

A clean, responsive personal portfolio website for a fresher Data Analyst. Built with plain HTML, CSS, and JavaScript — no frameworks, no build steps. Deploy in minutes.

## 🚀 Tech used
- Pure HTML5 / CSS3 / Vanilla JS
- Google Fonts (Space Grotesk + Space Mono)
- Deployed on Vercel (static)

## 📁 File structure
```
portfolio/
├── index.html       ← entire site (single file)
├── README.md
└── vercel.json      ← tells Vercel to serve index.html
```

## 🌐 Deploy on Vercel (free)

1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com) → **New Project** → Import your GitHub repo.
3. Vercel auto-detects static HTML — click **Deploy**.
4. Your portfolio is live at `https://your-project.vercel.app` 🎉
